# Corndog Kane

Source aplikasi HRIS, operasional outlet, payroll, dan keuangan.

Untuk menjalankan demo gratis Render + Supabase, baca [DEMO-DEPLOYMENT.md](DEMO-DEPLOYMENT.md). Data contoh terpisah dari database asli.

Pengembangan: Node.js 24, pnpm 11.25.0, PostgreSQL. Pasang dependency dengan pnpm install, isi DATABASE_URL di .env.local, lalu jalankan pnpm dev. Build: pnpm build.
